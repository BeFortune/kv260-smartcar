# 路线 B cut2：conv0–2 INT8 PL 核 KV260 上板（2026-10-21）

**真实 KV260 PS+PL 运行，非仿真。** 离线录像 117 帧；未碰相机/串口/车辆/时钟/启动配置。

## 授权与操作
- 用户授权：下载一次 Overlay + 录像帧测试。用户在终端自行 `sudo -v`，AI 未接触密码。
- `Bitstream.download(overlay, overlay.parser)` 一次，未调用 `Overlay.download()` 时钟 setter。
- 编程前后 PL 时钟原始寄存器一致，fclk0 99.999 MHz，CPU 1333.32 MHz。唯一警告为已知 PYNQ 3.0.1 `_current_metadata.pkl` ResourceWarning。
- 结束时核 idle；437 次 START 全部完成，无超时。
- 副作用：板上原 r04 v2 被替换（未回退）；新建 `/lib/firmware/conv_front_int8_20261021.bin`。

## 性能（同进程，4 线程，300 次，warmup 20，不含 JPEG 解码）

| 路径 | P50 | P95 | P99 |
|---|---:|---:|---:|
| 纯 CPU FP32（预处理+整模型） | 25.50 | 34.54 | 51.70 |
| **PS+PL（查表预处理+PL+反量化+后半段）** | **19.65** | **21.46** | **33.42** |
