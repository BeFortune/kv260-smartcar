# 硬件搭建、接线与供电边界

本仓库的当前验收完全离线，但保留目标平台身份，避免把仿真接口写成任意板卡通用结论。

## 1. 平台与历史接法

- 板卡：KV260 / K26，HLS 器件为 `xck26-sfvc784-2LV-c`。
- 三路 USB 相机，模型顺序为左、前、右；YOLO 只使用前视原图。
- 电机执行：目标系统中由 STM32 负责，不在本仿真中模拟物理电机行为。

历史核对的 USB 接法：

| 设备 | 角色 | 物理口 |
|---|---|---|
| icSpring `2993:0858` | 左相机 | `1-1.2.1` |
| ARC USB 2.0 Camera `05a3:9230` | 前相机 | `1-1.4.2` |
| icSpring `2993:0858` | 右相机 | `1-1.4.1` |
| CH340 `1a86:7523` | STM32 串口 | `1-1.2.3` |

UART 为 115200、8N1，转换器与 STM32 共地，TX 接 PA3、RX 接 PA2，不接 VCC，TTL 为 3.3 V。开发板与车各自供电。左相机历史压测有少量丢帧，不能视为链路已完全可靠。

## 2. 用户 2026-10-30 确认的契约

以下为口头确认，未附独立日志或固件哈希核验：

- 当前车上 STM32 固件即本仓库分析的版本。
- 速度单位为 RPM，模型输出范围为 ±500；STM32 侧上限 999，不接受负值。
- 自动路径方向标志固定 `'1'`，负速度拒绝编码；连续拒绝达阈值后补停车帧。
- 物理急停按钮可用，正式计时后仍应能在数秒内按到。
- 左/右通道与物理轮的对应由原 NUC 同协议实车行驶隐式确认，但四个逻辑电机到物理轮的明细对应未记录。

源码量纲仍有一个未解决问题：采样常量 `0.1` 秒与 TIM6 推导 `0.01` 秒相差十倍。单位名称虽确认为 RPM，数值刻度是否校准仍需实测。驱动板零输入和负速度行为也未做隔离验证。

## 3. 不允许从本报告推出的结论

- 整数参考全链通过不等于物理 PL 已执行。
- 软件停车决定不等于车辆已停下。
- 报文编码成功不等于 STM32 ACK。
- Windows 离线耗时不等于 KV260 延迟或实时 15 Hz。
- 固定左 98 行候选不等于车辆到达出口。

任何 Overlay 下载、相机、串口、服务或车辆动作都需要单独授权。固定赛道圈数、终点、碰撞/出界判据和最终计时规则仍需确认。
